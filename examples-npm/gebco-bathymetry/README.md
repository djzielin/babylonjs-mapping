# GEBCO Bathymetry

This example streams the colour-shaded GEBCO global bathymetric grid into a
Babylon.js tileset using `RasterGEBCO`. It opens on the Mariana Trench region;
drag to orbit and scroll to zoom.

Run it with:

```bash
npm install
npm run start
```

The imagery comes from the [GEBCO Web Map Service](https://www.gebco.net/data-products/gebco-web-services/web-map-service/).
The complete grids can be downloaded for offline workflows from
[download.gebco.net](https://download.gebco.net/). GEBCO imagery is for
visualization and is not intended for navigation or safety-at-sea purposes.
